# Food Quality Inspector

1. Copy `.env.example` and rename the copy to `.env`.
2. Paste your Gemini API key in `.env`.
3. Run `npm.cmd install`.
4. Run `npm.cmd start`.
5. Open http://localhost:3000

The quality score is generated separately for each captured image using Gemini. Results are saved in browser local storage. Click any history card to open the full inspection details page.
